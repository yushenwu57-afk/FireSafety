# FireWise 游戏设计文档（简版）

## 1. 游戏概述

FireWise 是一款以家庭消防安全为主题的第一人称 3D 教育游戏。玩家在室内场景中发现火灾隐患，通过行动选择应对险情，并根据选择获得结果反馈与评级。

设计目标是让玩家在情境体验中理解：及时发现危险、合理应对火情、优先安全撤离，以及撤离后避免再次进入危险区域。目标玩家为需要学习基础消防安全知识的普通用户。

## 2. 核心玩法

**观察环境 → 发现危险 → 作出选择 → 看到后果 → 完成关卡并复盘。**

- **探索：**使用 WASD 移动、鼠标观察，靠近可交互目标后按 E 操作。
- **决策：**关键节点弹出情境说明与行动选项，玩家通过点击选择推进流程。
- **反馈：**通过烟雾、火焰、危险提示及文字说明表现情境变化，让玩家理解行动后果。
- **纠错：**部分错误会提供补救机会，及时改正可以继续完成关卡，但原有错误仍计入评价。

## 3. 关卡设计

| 关卡 | 情境与流程 | 学习目标 |
| --- | --- | --- |
| 第一关：厨房火情应对 | 探索厨房并发现锅具起火，在关闭炉灶、处理火焰及火势升级后的撤离求助等节点作出选择。未及时发现危险或沿失败分支行动会导致关卡失败。 | 识别火灾隐患，理解不同处置方式的后果，并判断何时应撤离求助。 |
| 第二关：火灾撤离 | 厨房火势蔓延，玩家决定是否立即撤离，沿路线移动，并选择是否返回厨房；到达室外后，决定留在安全地点求助或返回取手机。 | 生命安全优先于财物，持续沿安全路线撤离，到达安全地点后不再返回。 |

第二关将步行探索与决策交替安排，玩家需要实际到达对应地点，才会触发下一段选择。

## 4. 评价与复盘

游戏记录安全行为、普通错误、严重错误和补救行为，结算时显示 **S / A / B / C** 评级及行为反馈。

- **S：**成功完成，且没有错误。
- **A：**成功完成，但存在普通错误；第二关对应一次普通错误。
- **B：**成功完成，但存在严重错误；第二关累计两次及以上普通错误也归入此级。
- **C：**未及时发现危险或触发失败结局。

评价重点是玩家的判断过程与错误原因。结算后可重玩，通过不同选择比较结果。

## 5. 画面与界面

采用低多边形室内场景，以熟悉的家庭环境降低理解门槛，使用火焰、烟雾和声音营造紧迫感。界面提供目标提示、交互准星、决策面板和结算反馈；按 ESC 可打开暂停菜单，继续游戏、重玩或返回主菜单。

## 6. 设计重点

以简洁操作和清晰后果突出消防学习内容。两个关卡分别训练“发现与应对”和“撤离与避险”，通过允许补救、保留错误记录与结算复盘，鼓励玩家理解原因并改进判断。

---

本文依据当前项目的两个关卡与评价逻辑整理，描述游戏内的情境设计。
